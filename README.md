# Tools

Small, focused browser-based utilities. No installs, no accounts, no data leaves your machine.

Live at: **https://jonathanwohl.github.io/tools/**

## Tools

| Tool | Description |
|------|-------------|
| [G-Code Feed Rate Modifier](gcode-feed-rate/) | Visualize a G-code tool path and selectively adjust feed rates by region |

## Adding a new tool

1. Create a new folder: `mkdir my-tool-name`
2. Drop an `index.html` in it (self-contained — no build step needed)
3. Add a card to the root `index.html` grid
4. Push — GitHub Pages deploys automatically

## Deployment

Hosted via GitHub Pages. Enable in **Settings → Pages → Deploy from branch → `main` / `root`**.
